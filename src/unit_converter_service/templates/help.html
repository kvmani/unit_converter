SCIENTIFIC GUIDE

Unit conversion

Parse a physical quantity, resolve its unit definition, verify that source and target have the same dimensionality, then apply the registry's scale and any required offset.

Main equations

\[ x_{B} \;=\; x_{A}\,\frac{s_{A}}{s_{B}} \]

Multiplicative units share a base-unit bridge, so the same physical quantity is recovered exactly.

\[ T_{\mathrm{K}} \;=\; T_{^{\circ}\mathrm{C}} + 273.15 \]

Absolute temperature is affine. Temperature intervals use the scale only, with no offset.

\[ \dim\bigl(q_{\text{source}}\bigr) \;=\; \dim\bigl(q_{\text{target}}\bigr) \;=\; \mathsf{L}^{\alpha}\mathsf{M}^{\beta}\mathsf{T}^{\gamma}\cdots \]

A conversion is valid only when both dimensionalities match exactly.

where
\(x_{A},\,x_{B}\)magnitude in the source and target unit
\(s_{A},\,s_{B}\)scale of each unit relative to the base unit
\(\mathsf{L},\mathsf{M},\mathsf{T}\)base dimensions of length, mass, and time
\(\alpha,\beta,\gamma\)integer exponents of each base dimension

Critical inputs

Magnitude
The numeric value being transformed.
Source and target
Define dimensionality, scale, and possible offsets.
Absolute or interval
Prevents a temperature difference from being treated as an absolute temperature.
Compound expression
Preserves dimensional algebra through multiplication and division.

Failure modes

  • Dimensionally incompatible conversions are rejected.
  • Ambiguous abbreviations should be replaced by explicit unit names.
  • A correct conversion cannot validate the measurement itself.

Privacy

This service runs on the office intranet. Conversions are computed in memory for the duration of your request, nothing is stored, and no personal information is collected.

Worked checks

  • \(1\,\mathrm{MPa} = 1\,\mathrm{N/mm^{2}}\)
  • \(25\,^{\circ}\mathrm{C} = 298.15\,\mathrm{K}\) (absolute)
  • \(\Delta 25\,^{\circ}\mathrm{C} = 25\,\mathrm{K}\) (interval)
  • \(1\,\mu\Omega\!\cdot\!\mathrm{cm} = 10^{-8}\,\Omega\!\cdot\!\mathrm{m}\)
